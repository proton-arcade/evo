The screen

DOM, state and interactions in js/ui/custom.js.

Responsibility

js/ui/custom.js is the DOM and interaction layer around pure library and rendering helpers. It owns screen lifecycle, manifest requests, temporary dropped files, rendering, carousel timing, the Explore panel and user-facing actions.

Screen lifecycle and state

  • show() initializes load status, featured index, view mode, panel state and transient drawing references, then builds, binds, renders and loads.
  • hide() invalidates in-flight work with a token, stops rotation and timers, detaches document listeners and releases canvas references.
  • resize() redraws the hero, every visible poster and the Explore cover without rebuilding the data model.
  • Files added by drop or picker live in module memory for the page session and can override a same-id manifest entry without writing into cc/.

Data loading

The screen fetches cc/index.json with cache: "no-store", sanitizes the manifest through CustomLibrary.parseManifest, then fetches every listed file. A monotonically increasing token prevents a stale refresh from replacing newer state after navigation or another refresh.

File-picker and drop input share addFiles. Inputs must end in .json and stay below 8 MB before the library parser runs. Failures remain visible by filename; valid session files are merged into the shelf.

Rendering and navigation

  • The first six entries can rotate as featured creatures every five seconds.
  • Rotation pauses on hover, keyboard focus, an open panel, an app modal, a hidden tab or reduced-motion preference.
  • Rows are produced from library data; poster buttons carry descriptive accessible labels and open Explore.
  • Explore marks the page behind it inert and aria-hidden, focuses Back, closes on Escape and returns focus to its opener.
  • Notices are alerts/status messages; the toast is an atomic polite live region.

Actions

  • SimulateCalls the shared action-brain chooser without first adding the design to My Creatures.
  • CopyCalls idempotent library logic and reports created, topped-up or already-present state.
  • Copy JSONUses the Clipboard API in a secure context and falls back to a selected read-only textarea modal.
  • Add file / dropParses into session state; never writes to the repository or browser library.
