Shared refactors

The app and editor paths shared by the feature.

Why these refactors exist

The original Custom Creatures feature needed two capabilities that had previously lived inside individual screens: drawing an unopened design and launching a simulation with an action-specific saved brain. Those paths were extracted rather than duplicated.

js/ui/app.js

Multi-action storage

Library entries can carry independent profiles for Running, Jumping, Obstacle Jump, Climbing and Flying. Storage normalizes known objective keys, keeps the compatibility evolvedCreature alias and updates one action without erasing the others.

Shared launch path

  • App.launchSimulation(design, designId, objective, profile) chooses objective settings, profile/default network settings and profile/default scene.
  • A supplied chromosome seeds CurrentChromosomes; its generation compatibility field is retained.
  • A My Creatures id is carried when present. A Custom Creatures simulation passes no id, preserving its read-only status.
  • App.chooseActionBrain builds the five-action dialog. Saved actions are labelled with generation; missing actions are labelled for training.

My Creatures and Custom Creatures both call these helpers, so chooser wording and continuation behavior cannot drift.

js/ui/editor.js

The editor delegates static render-model construction and initial camera framing to EVO.ViewModel. Selection overlays, pending-tool previews, hit behavior and the editor render loop remain in the editor. The extraction is deliberately narrow.

buildRenderModel: function () {
  return EVO.ViewModel.buildRenderModel(this.builder.design);
},

frameDesign: function () {
  EVO.ViewModel.frameDesign(this.builder.design, this.camera);
}

Script loading

index.html loads customLibrary.js with core data, then viewModel.js after the renderer, and finally custom.js with the UI screens. The order supplies every dependency without a module loader or build step.

Restyle impact

The light rebuild does not change app.js or editor.js. Browser verification exercised the shared chooser through to a simulation after the new controls were installed.
