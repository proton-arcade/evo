Drawing designs

Static creature drawing and the editor palette.

Shared render models

js/render/viewModel.js turns a static CreatureDesign into the object shape expected by Renderer.drawCreature. Joints get lightweight bodies, bones resolve joint references and geometry, muscles resolve bones, and decorations carry their attachment transforms.

Safe and strict paths

buildRenderModel

The editor-compatible path preserves every decoded component. It assumes a valid design and is useful where invalid references should be visible as an error.

buildSafeRenderModel

The poster path filters a bone missing either joint, then removes muscles and decorations that depend on filtered bones. A damaged preview cannot crash the renderer.

Framing

  • designBounds measures joint extents and returns null for an empty design.
  • frameDesign retains the editor’s original centering and zoom rules.
  • fitCamera fits a design inside a fractional canvas region, accounting for wide heroes, tall cards and text occupying part of a cover.

The rebuilt poster path

The prior poster renderer created a dark radial gradient, temporarily changed global renderer colors to pale bones and restored them afterward. That made the canvases internally dark even after surrounding CSS was changed.

The rebuilt drawPoster uses only shared renderer operations:

Renderer.drawBackground(ctx, camera);
if (options.grid) {
  Renderer.drawGrid(ctx, camera, visibility, gridSize);
}
Renderer.drawCreature(ctx, buildSafeRenderModel(design), camera, options);
  • The backing store is still sized to the app’s capped display pixel ratio.
  • The renderer’s #ededed background and normal red joints, dark bones and neutral muscles are preserved.
  • options.grid can be true for the default subtle visibility or a numeric visibility.
  • options.gridSize can override the shared setting.
  • try/finally still guarantees canvas-state restoration, but no global palette mutation is needed.

Where the grid is used

The large featured hero and Explore cover request the grid. Small shelf posters omit it for clarity, but use the same light background and creature colors. This is the “optional grid” boundary: one renderer, chosen per use.
