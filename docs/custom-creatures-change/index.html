Change record

What changed, why it changed and what was checked

One HTML page is provided for each section. This index is the reading order and the short version.

Interpretation used. “Same layout” means preserving the Custom Creatures information architecture and interactions while replacing its visual theme with evo’s existing light CSS language.

Theme follow-up. The app now has a Settings-controlled Light / Dark theme. Custom Creatures follows the global theme tokens and canvas palette; this does not restore the removed catalogue-only dark skin.

Result

Presentation

The scoped dark palette, custom type scale, dark top-bar overrides and one-off action-button skins were removed. The page now uses #ededed, #f7f7f7, the app’s line greys and #1b1b1b ink.

Components

Hero, view-switch, Explore and copy/simulate actions use .evo-button. Explore uses the same Back / title / right-slot top bar as the parent screen.

Creature art

Posters no longer invert bones for a dark canvas. drawPoster uses the editor background and renderer palette, with the renderer’s grid available as an option.

Structure retained

The cover fade, snap-scrolling shelves, Grid mode, slide-in panel, file drop affordance, notices, toast, keyboard behavior and reduced-motion treatment remain.
