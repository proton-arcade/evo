Detailed record

Rebuilt on the existing CSS

The layout stayed. The borrowed theme did not.

The interpretation

The requested “same layout” is treated as a structural requirement, not a request to preserve the arcade skin. The hierarchy stays recognizable: a top bar, a cinematic featured region, shelves of posters, an alternate grid and a full-screen Explore view. The presentation now follows the application that contains it.

Kept: content order, dimensions that create a cover-like hero, canvas artwork, fade into page color, five-second featured rotation, snap points, panel transition, toast and drop outline.

What was removed

  • The --cc-bg, --cc-bar, --cc-panel, --cc-deep, red-accent and dark-scrollbar palette.
  • Scoped overrides that recolored .top-bar, .back-button and .evo-button.
  • The Arial-only type override and the Custom screen’s larger base font.
  • White-on-black text shadows, black cover gradients, glowing radial canvas background and white bone override.
  • One-off .play-btn, .flat-btn, .ghost, .play-cta and round icon-back control styles.

What replaced it

Shared controls

Actions are created with UI.makeButton, which supplies .evo-button and the shared primary modifier. Back remains the application’s .back-button.

Shared color language

The Custom screen uses the same light-grey background, off-white panels, neutral lines, dark ink and blue focus outline visible elsewhere in evo.

Shared typography

The app font is inherited. Interface labels use the existing uppercase, tracked-label convention; creature names and descriptive copy retain readable casing.

Shared drawings

Cover and poster canvases use Renderer.COLORS unchanged. Large covers opt into the same subtle grid primitive used by the editor.
