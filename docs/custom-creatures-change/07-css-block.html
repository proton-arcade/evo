The CSS block

The scoped light catalogue implementation.

Scope

The Custom Creatures block remains scoped beneath .screen-custom (or the unique #ccDetails panel), so its catalogue geometry does not alter Home, Editor, Simulation, Ecosystem or Gallery. The rebuild reduces the block from a theme-within-a-theme to layout and component-specific styling.

Deleted theme layer

The following no longer appear in the Custom CSS: dark custom properties, black panel backgrounds, white copy, red streaming-service accent, dark top-bar rules and selectors that recolor .back-button or .evo-button. Shared button rules now work without a scoped correction.

Typography

No screen-specific font family or 16px base override remains. Inherited Helvetica/Arial matches the app. Kicker, metadata, toolbar, row headings, poster labels, detail metadata and chips use uppercase plus measured letter spacing, matching evo’s existing control-label idiom.

Hero and cover fade

The canvas is light. A transparent-to-#ededed gradient fades its lower grid and creature into the copy area rather than darkening the image. Explore uses the same idea. Text shadows are unnecessary and were removed.

Rows and cards

  • Horizontal galleries keep scroll-snap-type: x proximity and touch momentum.
  • Cards use neutral borders and the canvas background; hover lifts two pixels and darkens only the border.
  • The label fade resolves to the off-white panel color and uses dark uppercase text.
  • Grid remains auto-filling on wide screens and becomes two equal columns below 520px.

Explore layout

The panel is a flex column: shared top bar, independently scrolling main content and a light footer containing the shared primary Simulate button. This removes absolute custom header/footer skinning while keeping the full-screen slide transform.

Accessibility and motion

  • Focus-visible outlines use high-contrast blue and a three-pixel separation.
  • Thin carousel marks retain enlarged pseudo-element hit areas.
  • Coarse-pointer sizing continues to come from the app’s global button rules.
  • The existing reduced-motion block disables transitions and animations inside the screen.
